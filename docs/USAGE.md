# Miku39 v1.4.4 · 初音未来 Komari 主题

现在可以本地上传图片或输入图片直链作为自定义背景，选择保存在当前浏览器，加载成功后立即预览。服务器显示尺寸继续支持极简、紧凑、标准和放大四档，可在主题设置顶部即时切换；卡片宽度、留白、字号、测速曲线和表格行高一起调整。新访客默认紧凑，选择自动保存在当前浏览器。价格、到期日期和剩余天数仍合并为可换行的信息栏。地球上的每台服务器现在支持自定义标记名称，随时编辑或恢复原名，保存于当前浏览器。继续保留 v1.4 的资源历史修复、服务器流量、价格与到期时间，以及所有可定位服务器的位置、真实采样音轨、稳定局部刷新、可调玻璃、三张背景和四款初音伙伴。

## 安装与预览

1. 在 Komari 主题管理中上传 `komari-theme-miku39-v1.4.4.zip`。已有同名主题时，按后台的更新或覆盖流程替换。
2. 启用 **初音未来 · Miku39**，刷新首页。缓存未更新时，使用浏览器强制刷新。
3. 右上角「切换背景」可本地上传图片、应用图片链接或选择内置背景；「主题设置」顶部可选择服务器显示尺寸，也可调整玻璃、伙伴、采样节拍、地球画质和辉光；地球旁可调整汇聚区域。位置列表中点击服务器右侧的铅笔，自定义标记名称并保存；同位置的服务器选择弹窗也有编辑入口。
4. 管理后台 **Miku 主题设置** 可指定首次访问默认值。访客在当前浏览器保存的偏好优先。

离线预览由 `scripts/make_preview.py` 生成，输出的 `miku39-v1.4.4-preview.html` 可直接打开，图片、纹理、国旗、样式和脚本全部内嵌。六个模拟服务器明确标为「演示数据」，不连接探针或登录服务。

安装包根目录包含 `komari-theme.json`，生产页面位于 `dist/`，主题短名仍为 `miku39`。无需 npm 安装、外部 CDN、字体服务或图床。

## v1.4.4 自定义背景

- 打开右上角「切换背景」：本地上传图片，或输入图片直链并点击「应用链接」。选择前显示当前背景预览，读取成功后才替换原图。
- 本地图片支持 JPG、PNG、WebP、GIF、AVIF，大小上限 10 MiB；保留原始图片及动画，保存在当前站点、当前浏览器的图片存储中，无需上传到 Komari 服务器。刷新后会重新生成有效图片地址，避免保存已经失效的临时地址。
- 图片链接支持完整 HTTP(S) 地址，不需要跨域读取图片字节。HTTPS 页面要求 HTTPS 图片；无法直接加载的链接显示错误并保留当前背景，不猜测网页中的图片地址。
- 本地图片和链接均用于页面背景及首页横幅，继续支持遮罩、模糊、明暗外观和玻璃；自定义图片不参与内置背景自动轮换。
- 随时点内置背景切回，或点击「恢复背景默认值」回到晴空初音。已保存的本地图片与上次链接保留，可点击「使用已保存图片」再次启用；恢复全部外观设置会清空链接偏好，仍保留本地图片。
- 文件类型、大小或内容不合格时，以及图片存储无法写入时，保持此前已保存图片与当前背景。加载过程中切回内置背景、恢复设置或离开页面，会取消未完成的选择。
- 自定义背景仅在当前浏览器、当前站点生效。更换浏览器、站点地址或清除网站数据后需要重新选择；链接背景需要链接继续可访问。浏览器不支持图片存储时会提示改用链接。

## 实时稳定性与动效

保留 v1.2 的局部 DOM 更新：卡片、表格行、图片、SVG 和音轨游标保持元素身份，只修改变化的文本、属性及路径。相同内容不触发更新；排序移动现有服务器。测速刷新不会重建整块音轨或从头播放装饰动画。

地球复用 GPU 纹理、程序和缓冲区，只有实际像素尺寸变化才重设画布。WebGL 模式绘制目标约 30 帧/秒；省电与兼容模式约 16 帧/秒，像素倍率分别设有上限。这些是调度目标，不是目标设备的帧率测试结果。

页面隐藏、地球离开视区、弹窗打开时停绘；暂停更新、关闭主题动效或系统选择减少动态效果时停止持续动画。音轨游标为缓慢的装饰，不表示新增测量或实际播放音频。纹理中的亮暗细节也是舞台装饰，不表示城市人口、实时昼夜或实测地形。

## 延迟与丢包的实际含义

延迟来自 **Agent 对 Komari 后台配置的公开 Ping 任务进行的测量**，并非访客浏览器到服务器的延迟。请在后台添加公开任务并关联服务器；没有任务或记录时显示明确空状态。卡片最多显示三个任务，表格显示首个任务；中国三网名称优先。

首页读取最近一小时记录，约每 60 秒刷新，最多三台服务器请求同时进行。刷新按钮只读取已有记录；页面隐藏、暂停更新、关闭卡片测速时取消相关请求。接口使用同源的 `GET /api/task/ping` 与 `GET /api/records/ping?uuid=...&hours=...`，沿用 Komari 访问权限，不使用管理员 API Key。

负值表示失败/超时，计入丢包，不计入平均和 P95；未知值显示 `—`，保留缺口，不补零。卡片丢包数值统计近一小时，详情与网络页面统计所选时间范围；丢包曲线按各采样之前 5 分钟（含边界）的有效测量计算失败比例。各任务单独计算，汇总按测量次数加权。采样柱取每个时间分箱内的真实峰值，断拍仅标实际失败事件；柱高不会随装饰游标变动。

超过任务间隔三倍（至少三分钟）的采样以 `*` 标记。离线或连接未确认时注明历史采样；更新失败保留上次记录并给出提示。详情保留 1 / 6 / 24 / 72 小时范围、平均、P95 和汇总丢包。任务元数据缺失时按真实任务 ID 显示。

## 资源历史、流量与计费

历史来自同源 `GET /api/records/load?uuid=...&load_type=all&hours=...`。部分后端重构记录的 `ram_total`、`disk_total` 为零，旧版使用空值回退时会保留零分母，从而丢失使用率曲线。新版只接受正数容量；采样自身的有效总容量优先，否则使用服务器基础容量，最后使用最近一次上报容量。后两项是容量参考，不代表该时刻容量有独立采样；已用量和时间仍来自真实历史记录。没有任何有效容量或已用量时不补造百分比。

流量来自最近上报的 `network.totalUp` / `totalDown`；设置配额时采用后台的 `traffic_limit_type`（`sum`、`max`、`min`、`up`、`down`）。没有配额仍显示累计流量，缺少必要计数时显示 `—`，不补零；单向口径只要求对应计数。累计值可能随 Agent 或后台计数方式变化，不作为自然月账单。

价格直接读取 `price`、`currency`、`billing_cycle`，不自动换汇或猜测币种。`price=-1` 显示免费；零、缺失和其他无效价格显示未设置。周期按后台实际天数显示。到期读取 `expired_at`，兼容带时区的 ISO 和空格分隔时间及长小数秒；空值、无效日期和 `0001` 年哨兵均显示未设置。日期按访客浏览器时区显示。主题不写入服务器计费配置；需要在 Komari 后台填写价格、周期和到期时间。

## 地球与汇聚区域

- 新访问和旧版默认迁移采用 **中国（全国）**，标签仅显示“中国”，使用全国代表坐标；已明确保存的 v1.2 区域选择继续保留。
- 可选全国、34 个省级行政区或自定义区域。省级地区按 23 个省、5 个自治区、4 个直辖市、2 个特别行政区分组，使用代表点。
- 自定义区域接受 32 字以内名称、纬度 −90～90、经度 −180～180。点击「应用区域」保存；无效输入不覆盖上次有效位置。
- 流光方向为 **VPS → 所选汇聚点**，强弱和速度参考在线服务器的总上传速率。**这是流向示意，不是实际流向中国的流量分类或路由追踪**；Komari 公开快照没有目的地流量分类。
- 服务器合法经纬度优先；否则按名称识别出的城市或国家/地区代表点示意定位。页面注明定位方式，不调用外部 IP 定位服务。无法定位的服务器计入提示，不随机放置。
- 所有可定位服务器保留位置标记，在线为青绿、离线为粉色空心、待确认为暖黄。相同坐标聚合显示数量，不通过随机偏移假造位置；点击聚合标记可选择具体服务器。
- 右侧位置列表支持鼠标、触摸和键盘选择聚焦。地图仅显示球体正面标记，名称避让并限制数量；列表仍保留全部可定位服务器。
- 只显示确认在线且上传大于零的流光，最多 32 条；集群统计仍覆盖所有在线服务器。
- 地球使用 Natural Earth 物理陆地与海岸数据，没有行政边界图层；数据来源、许可与可复现生成脚本见 `data/README.md`、`ASSETS.md`。

## 玻璃、伙伴与兼容偏好

面板不透明度 10–100%、毛玻璃 0–40px、边框亮度 0–100%；可开启/关闭玻璃并选择清透、柔雾、清晰预设。四款伙伴为经典初音、葱葱日常、星航宇宙、应援歌姬，可切换或隐藏。

随包提供 69 个常用地区 SVG 图标，支持地区代码、中英文名和国旗 Emoji。未覆盖的有效地区显示代码，未知地区显示中性符号，不猜测地址所属国家。

沿用 `miku39.preferences.v1`、`miku39.favorites.v1` 和 `appearance`，自动补齐新增字段，保留原收藏、背景、玻璃和区域选择；自定义标记名称单独保存在 `miku39.globe-labels.v1`。新访客默认紧凑显示，面板不透明度 64%、模糊 24px、边框亮度 32%、采样节拍开启、地球自适应画质、辉光 70%。后台主题元数据与配置栏目统一为 Miku；Komari 原生管理页面和其他已安装主题不属于本安装包。
